cipherbench — zsh ~/toolkit

Ethical Hacking Kitchen

Twenty-one encoders, decoders, ciphers, and formatters for puzzle-solving and everyday dev work — Base64/32, hex, URL, Caesar/ROT, Vigenère, Atbash, Morse, binary, hashing, JWT, JSON, timestamps, UUID/string generation, text tools, AES-GCM, Gzip, HTML entities, Unicode escapes, IOC defanging, and a text extractor. Everything runs locally in this page — nothing you type leaves your browser.

$ digest

one-way — for checksums / lookups, not for hiding secrets
MD5 is included for recognizing legacy hashes only — it's cryptographically broken. Don't use it, or raw SHA‑256, to store real passwords; that needs a slow, salted algorithm like bcrypt or Argon2, done server‑side.

$ jwt decode

reads header + payload only — does not verify the signature
A decoded payload is not proof of anything — anyone can craft one. Only a signature check against the real secret or public key says a token is genuine.

$ wc / tr

case conversion, reversing, counting
0 characters · 0 words · 0 lines
Mirror flips the text left-to-right and swaps each letter for its closest mirrored look-alike (b↔d, p↔q, s↔ꙅ…), the way it'd read held up to a mirror. It's a lossy visual trick, not a cipher — some characters have no true mirror glyph and are approximated. De-mirror reverses the same transform.

$ openssl aes-256-gcm

AES-GCM via WebCrypto — password-derived key (PBKDF2)
Encrypt produces one Base64 blob (salt + IV + ciphertext bundled together); feed that same blob back in with the same passphrase to decrypt. This is real AES-256-GCM, but a page like this is for learning the mechanics, not for protecting anything that actually matters.
